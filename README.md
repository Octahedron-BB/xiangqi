# 象棋演义 · Xiangqi Master

现代化、轻量纯前端的中国象棋沉浸式网页游戏。无需复杂环境与外部后端，打开浏览器即可开局！

包含 **「经典博弈」**、**「劫棋演义（Roguelike 肉鸽战役）」** 与 **「自由演武沙盒」** 三大独立模式。

> 🌐 **在线即开即玩**：[https://octahedron-bb.github.io/xiangqi/](https://octahedron-bb.github.io/xiangqi/)  
> 随时随地，无需下载安装，手机与电脑浏览器点开秒玩！

---

## ✨ 核心特色

- 🎋 **传统国风美学**：水墨木质纹理棋盘、红黑正统书法楷体棋子、原汁原味流畅平滑走子动效（经典与肉鸽全模式支持）与中文棋谱记法（如「炮二平五」、「马8进7」）。
- ⚡ **本地极速运算**：基于 WebAssembly 编译的智能博弈内核，毫秒级推演与深度评估，纯本地运行，零网络延迟。
- 🏆 **11 阶传统棋力评级**：从入门学童到绝巅化境（搜索深度 22），提供丰富多样的对手风格，支持人机对决与 AI 双向互搏。
- ⚔️ **原创 Roguelike「劫棋演义」**：
  - 20 关独立肉鸽闯关玩法，部队跨关战损继承机制。
  - 首领战（第 10 关「镇关大将」· 绝影神骑、第 20 关「天武神尊」· 天武双绝）与赏金关卡。
  - **车、马、炮、兵双分支专精路线**（如神后、雷霆万钧、天马、神火游击等）。
  - **八大战术宝物系统**（《弃子争先》、《借尸还魂》、《背水一战》、《瞒天过海》、《金蝉脱壳》、《连环铁锁》、《摸金校尉》、《重赏勇夫》）。
  - **战备整补与子力备用库**：关卡结算自动补给，支持战局中随时将备用子力空投部署至初始阵地。
- 🛠️ **独立演武沙盒（调试模式）**：自由摆盘、任意增减/移动棋子、实时配置双方技能分支与 Tier 等级、随时载入 20 关预设与机器人交锋实测。
- ⚖️ **严谨象棋规则**：严格遵循中国象棋竞赛规则，精准实现将帅照面拦截、困毙、绝杀与三次重复局面长将变招/判负。
- 💾 **轻量断点续玩**：依托浏览器本地轻量存储，随时随地自动保存/读取对战进度。

## 🎮 玩法模式说明

### 1. 经典博弈模式 (`index.html`)

提供标准正规的中国象棋单局对战体验：
- **执子选择**：自由选择执红（先手）或执黑（后手）。
- **悔棋与提示**：支持随时悔棋，或呼叫 AI 提示最佳着法（高亮箭头与中文记谱）。
- **局势评估**：实时展示当前局面胜率条与子力分值评估。
- **FEN 支持**：随时一键复制当前局面 FEN 串，或粘贴载入任意外部排局。

### 2. 劫棋演义（Roguelike 闯关）(`rogue.html`)

从「一车双兵」起步，一路过关斩将，通过战利品三选一升级棋子、招募部队、获取宝物：

#### 核心机制
1. **部队永久损耗与跨关继承**：红方阵亡的大子（车/马/炮等）不会在过关后凭空复活。
2. **擒王与赏金目标**：全关卡统一以「将死对方」为胜利目标；在特定悬赏关卡（第 4、8、12、16、18 关），斩杀敌方子力或达成全歼可获得丰厚金币奖励。
3. **首领 Boss 战与敌方精锐进阶**：
   - **特色精锐关卡**：如第 4 关黑卒横行疾步、第 8 关象免塞眼、第 11 关万马奔腾（黑马免蹩腿）、第 12 关连珠重炮（隔二子打）、第 13 关破阵重车（贯石跃友军）、第 14 关神火近身炮、第 15 关铁骑突刺、第 16 关八方战车、第 17 关群煞出宫、第 18 关狂涛战阵等。
   - **第 10 关首领【镇关大将】**：敌方全军黑马获得「不蹩腿」机动特性。
   - **第 20 关首领【天武神尊】**：敌方战车全员化为「后」可斜向任意滑行，黑马全部「不蹩腿」。
4. **兵种进阶双分支（路线甲 / 路线乙）**：
   - **兵**：路线甲【陷阵】（冲两格 / 横行 / 王步八方行）或 路线乙【战阵】（横行疾步 / 金戈斜刺 / 神兵破阵）。
   - **炮**：路线甲【重炮】（隔二子 / 隔三子 / 贯通炮超远狙击）或 路线乙【神火】（近身免架 / 翻山游击 / 自充炮台）。
   - **马**：路线甲【天马】（不蹩腿 / 走目 / 天马田字跳跃）或 路线乙【铁骑】（斜步 / 近身刺 / 连环步可选追加位移）。
   - **车**：路线甲【神后】（斜滑 1 格 / 2 格 / 全斜线神后）或 路线乙【重辇】（贯石跃友军 / 隔子冲杀 / 雷霆万钧超远突袭）。
5. **八大战术宝物**：
   - 《弃子争先》：弃大子（车/马/炮）后立即获得额外行动回合（若第 1 步叫将则按双招规则提前结束连走，逼对方应将）。
   - 《借尸还魂》：每关限 1 次，击杀黑方车/马/炮时化为己用入备库。
   - 《背水一战》：己方在场子力≤4（帅+至多3子）时全员狂暴：帅冲出九宫走米字，仕相永久突破限制，马免蹩跳田，车跃友军斜击。
   - 《瞒天过海》：开局前 2 回合黑方无法吃红子；仕永久出九宫全斜线滑行，相永久渡河且免塞象眼。
   - 《金蝉脱壳》：每关限 1 次，主帅濒危/被杀时与最近的己方兵/仕移形换位脱险。
   - 《连环铁锁》：结阵御敌。敌方兵卒无法吃任何有友军守护（生根）的红子；敌方黑马无法吃任何处于互保状态的红子。
   - 《摸金校尉》：战局吃子每子 +1 金，悬赏关赏金额外 +50%。
   - 《重赏勇夫》：补给铺进店时必定随机赠送一件 0 金币商品。
6. **备用库与空投部署**：
   - 随关卡推进自动获得兵马炮补给，超出出战上限者进入备库。
   - 每关开局自动回填战损部队；对战中点击备库棋子，可将其空投至己方出生空位！

### 3. 自由演武沙盒 (`debug.html`)

为研究对局、设计残局和测试新技能量身打造的独立沙盘：
- **任意加减子**：选定红/黑兵种，点击棋盘任意格子直接摆子；点击棋子即可直接除子。
- **任意移子**：自由拾起并放置任意棋子，不受规则约束地摆布局势。
- **强化实时调配**：自由勾选红黑双方的兵种分支（路线甲/乙）与 Tier 走法等级（T0 ~ T3）。
- **AI 交互对抗**：支持一键让黑方机器人根据当前自定义棋局与强化等级走下一步。
- **关卡一键载入**：随时一键还原全 20 关的初始布阵与首领特殊状态。
