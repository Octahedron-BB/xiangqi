# 象棋 Roguelike · 设计文档（v0.1 待审）

> 一句话：**象棋的走法 + 战棋的成长 + roguelike 的关卡**。
> 玩家一关一关打残局，每关胜利三选一强化自己的棋子；敌人有各自的特性；敌方棋子初始扣置（暗棋）。

---

## 0. 已锁定的决策

| 决策项 | 结论 | 影响 |
|---|---|---|
| 关卡形式 | **残局/中局开局**，一关 15–40 手 | 节奏快，每关天然不同，成长可写进起始局面 |
| 失败机制 | **帅护甲**（被将死扣 1，扣光 run 失败） | 有容错，但一局定不了生死 |
| 伤害模型 | **一击必杀**（无 HP、无伤害数字） | 保住象棋手感；升级只改**走法**和**特技** |
| 攻击/移动 | **半拆**：普通吃子=走上去占位；**炮与特技可原地开火** | 范围攻击有落脚点，但不破坏推进感 |
| 行动经济 | **1 步棋 + 1 次战技**（战技有冷却） | 保留象棋节奏，同时给战技留位置 |
| 迷雾 | **暗棋翻开**：敌方子扣置，接触/被攻击/移动才现形 | 信息不对称；实现只需渲染层 |
| 对手 AI | **自写**（alpha-beta）。Pikafish 保留为最终 Boss | 规则自由；Boss 战是纯正标准象棋 |

**范围变化（重要）**：因为要改走法 + 暗棋，Pikafish 无法作为常规对手。这不再是"改造象棋"，是"用象棋的走法写一个战棋"。经典模式（现有版本）完全不动，roguelike 是并列的第二个模式。

## 1. 核心规则

### 1.1 棋盘与走子
- 9×10 交叉点，红黑各 16 子，走法沿用中国象棋。
- **所有子一击必杀**：被吃的子立即移除。不存在血量、伤害、命中率。
- 帅/将仍不可照面；被将军必须应；将被将死 = 输。

### 1.2 半拆的三种吃子方式

| 方式 | 谁有 | 行为 |
|---|---|---|
| **走吃** | 全部棋子 | 走到目标格并移除该敌子（标准象棋，占位） |
| **开火** | 炮、部分战技 | 原地不动，移除射程内的敌子（不占位） |
| **溅射** | 炮 T2、部分战技 | 开火时额外移除命中格相邻的敌子 |

"开火"是战棋感的关键，但它被严格限制在**炮**和**少数战技**上，所以棋盘上 90% 的交互仍然是象棋。

### 1.3 回合流程

```
玩家回合
├─ 1 次走子（走吃 或 开火）
├─ 1 次战技（若不在冷却；强力战技额外消耗气）
└─ 结算：吃子触发被动、暗棋翻开、护甲变化
敌方回合
├─ 按 AI 决策走 1 子（部分敌人特性可以让它多走）
└─ 结算
```

### 1.4 关卡目标（不能全都只是"将死"）
残局里子力差距很大，"将死"作为唯一目标会让某些关变得无解或过于简单。所以每关带一个目标：

| 目标 | 判定 |
|---|---|
| **擒王** | 将死对方 |
| **歼灭** | 吃光对方所有非将子 |
| **夺旗** | 吃掉指定的"旗子"（通常是对方主力） |
| **守城** | 坚持 N 个自己的回合而不被将死 |

AI 不需要理解目标 —— 它照常按子力评估下棋；目标只是对玩家的胜利条件。这让关卡设计自由度极大，且实现成本为零。

### 1.5 和棋与长将

残局里"谁也赢不了"很常见，尤其是 AI 只剩一个车时会反复将军，把局面锁死。所以必须有重复局面判定，
否则一局会无限循环下去：

| 情况 | 判定 |
|---|---|
| AI 的一步会把局面带到第 3 次重复 | **AI 换一步别的走法**（避免自己把局面拖死） |
| 换无可换，且某一方在自己的**每一手**都将军 | 长将方判负（象棋规则） |
| 同一局面第 3 次出现，双方都不构成长将 | 判和 → 本关失败 |
| 步数超过关卡上限 | 本关失败 |

判定只看「重复循环内」的着法（从上一次出现同一局面到现在），所以循环前后无关的将军不会误伤。

**为什么不直接判 AI 输**：V1 里 AI 会自己钻进长将然后被判负，玩家赢得很莫名。
现在它在选招时就把「会重复」的走法排在后面，宁可换个计划。只有所有走法都会重复时才认账。

## 2. 属性系统（没有 HP，怎么表现"攻防成长"）

每个棋子有 3 个维度：

```
走法等级 MoveTier : 0 / 1 / 2 / 3     ← "攻击性"成长：能打到哪、能打几个
特技槽 SkillSlot  : 0–2 个被动/主动    ← "防御性"成长：免死、反击、警觉
气 Qi             : 全局资源            ← 强力战技的燃料
```

没有攻/防/血数值。用户想要的"攻击力加强"= 走法扩展 + 溅射；"防御力加强"= 免死/反击/警觉这类被动。

> **为什么不用 HP**：象棋的核心快感是"一步吃子、子力交换"，一旦引入血量，车吃车要打三回合、残局会黏住，节奏全毁。想要"伤害数字"的爽感，用**溅射**（一次杀多个）来替代。

### 2.1 子力值（用于平衡预算，不显示给玩家）

| 棋子 | T0 | T1 | T2 | T3 |
|---|---|---|---|---|
| 兵 | 1 | 2 | 3 | 4.5 |
| 士 | 2 | 3 | 4 | — |
| 象 | 2 | 3 | 4 | — |
| 马 | 4 | 5 | 6.5 | 8 |
| 炮 | 4.5 | 5.5 | 7 | 9 |
| 车 | 9 | 10 | 12 | 14 |
| 帅 | ∞ | — | — | — |

## 3. 升级树

### 兵（Pawn）
| Tier | 效果 | 备注 |
|---|---|---|
| T0 | 前 1 | 标准 |
| T1 | **前 1 或前 2**（中间必须空，第二格可以是敌子 → 能吃） | 大步推进，过河快一倍 |
| T2 | **+ 横走 1** | 过河兵的横切 |
| T3 | **+ 斜前 1** | 可以斜切，卡位能力暴增 |

> 兵是全部升级里最划算的：1 值的子升到 T3 变 4.5 值，且能配合炮架。

### 炮（Cannon）
| Tier | 效果 |
|---|---|
| T0 | 隔 1 子直线吃 |
| T1 | **可隔 2 子吃**（跳过任意 1–2 个子） |
| T2 | **战技「震爆」**：原地开火，命中格上下左右相邻的敌子一并击杀（冷却 3） |
| T3 | **近身炮**：紧邻的直线敌子无需炮架即可吃 |

### 马（Horse）
| Tier | 效果 |
|---|---|
| T0 | 日字 + 蹩腿 |
| T1 | **不蹩腿** |
| T2 | **走「目」**：额外可走 (1,3)/(3,1) 八个落点（「目」三格长一格宽，正如「日」两格长） |
| T3 | **战技「践踏」**：跳到目标格并额外击杀落点相邻的 1 个敌子 |

### 车（Rook）
| Tier | 效果 |
|---|---|
| T0 | 直线任意格 |
| T1 | **后**：额外可沿四条斜线任意滑（直走 + 斜走） |
| T2 | **被动「冲阵」**：直线吃子后，若正前方下一格为空，自动再进一格 |
| T3 | **被动「横扫」**：吃子时同时击杀该方向紧邻的下一个敌子 |

> **V0 实测后改的**
> - 车 T1 原本是「拐一次弯」，实测一对拐弯着法在空盘上就有 **81 个落点**（几乎全盘），
>   落点标记铺满棋盘、走子看起来像瞬移，且标准记谱写不出这种走法。改成「后」（直走 + 斜走），
>   落点上限 27 个，和国际象棋同一个直觉。
> - 炮 T3 原本是「无架」（直线第一个子直接吃），但那等于把炮变成车，炮就失去身份了。
>   改成「近身炮」：只有**紧邻**的敌子能免炮架吃。
> - 马 T2 最初写成「连走两个日字」，落点跨度到 (±4,±4)，明显不是「目」。现在按字面实现
>   「目」：三格长一格宽，即 (1,3)/(3,1) 八步。
>
> 这些改动同时降低了 `attacked()` 的复杂度 —— 任何「走法升级」都必须在 `attacked()`
> 里精确镜像一次，否则会出现「能吃将但不算将军」的死局。

### 士（Advisor）
| Tier | 效果 |
|---|---|
| T0 | 九宫内斜 1 |
| T1 | **九宫内斜 1–2** |
| T2 | **可出九宫**（斜线任意格） |

### 象（Elephant）
| Tier | 效果 |
|---|---|
| T0 | 田字 + 塞象眼 |
| T1 | **不塞象眼** |
| T2 | **可过河** |

### 帅（King）
不可升级。改为在奖励里获取「护甲 +1」「免死 1 次」这类专属被动。

## 4. 战技

每回合可放 **1 次**（有冷却）。标「气」的额外消耗气。

### 普通战技（选 1–2 个装进 2 个槽位）

| 战技 | 效果 | 冷却 |
|---|---|---|
| 突进 | 指定己方一子立刻再走一步（等于本回合第二次行动） | 4 |
| 铁壁 | 指定己方一子到下个己方回合前不可被吃 | 3 |
| 定身 | 指定敌方一子下回合不能动 | 3 |
| 移形 | 把一个己方子瞬移到任意空位（不能造成自己被将） | 4 |
| 探照 | 翻开 2 个暗置敌子 | 2 |
| 换位 | 交换两个己方子的位置 | 3 |

### 强力战技（消耗气，上限 2→5，每关开局回满）

| 战技 | 效果 | 气 |
|---|---|---|
| 炮击 | 选一条直线，击杀线上第一个敌子（无视炮架、无视距离） | 2 |
| 斩首 | 击杀任一非将敌子（精英子免疫） | 3 |
| 回春 | 护甲 +1（可超上限 1 点） | 2 |
| 援军 | 一个己方兵升到 T2 并放到己方底线空位 | 3 |
| 天眼 | 本关剩余时间内所有暗子对玩家可见 | 3 |

---

## 5. 被动特技（"防御力"在这里）

| 被动 | 效果 |
|---|---|
| 免死 | 该子本关第一次被吃时存活（一次性护盾，视觉上有金框） |
| 反噬 | 被吃时把攻击者一起带走（同归于尽） |
| 警觉 | 被暗子攻击时先翻开，且该次攻击由你决定是否接受 |
| 铁骨 | 不会被 T0 的兵吃掉 |
| 节流 | 每关开局气回满，且气上限 +1 |

## 6. 暗棋

| 规则 | 说明 |
|---|---|
| 初始 | 敌方所有子扣置，渲染成背面圆盘 |
| 翻开条件 | ① 与任一己方子 8 邻 ② 该敌子移动过 ③ 被己方攻击 ④ 探照/天眼 |
| 攻击暗子 | 允许。攻击时先翻开再结算 —— 你在赌它是不是车 |
| 玩家自己的子 | 始终明置 |

### 关键实现洞察

**AI 不需要处理隐藏信息。** 因为只有敌方扣置，AI 完全知道自己每一个子，而玩家的子全明置 —— 所以 AI 用**完全信息搜索**即可，不需要 determinization / MCTS 那一套。

信息劣势 100% 由玩家承担，这正好是 roguelike 想要的难度来源。补偿机制是「探照」「警觉」「天眼」三个战技。

## 7. 资源与失败

| 资源 | 初始 | 上限 | 恢复 |
|---|---|---|---|
| 护甲 Armor | 2 | 4 | 奖励 / 回春战技 |
| 气 Qi | 2 | 5 | 每关开局回满 |
| 步数限制 | 无（"守城"关反过来限回合） | — | — |

**被将死时**：消耗 1 点护甲，然后**续命**——把帅移到九宫内最近的安全格，若九宫无安全格则移除攻击线上的一个敌子。护甲为 0 时被将死 = run 结束。

## 8. 部队继承（V2 重构，当前实现）

**V1 的问题**：每关都是一个新的完整残局。结果是一局里我方只增不减——每关发一支新军，
奖励再往上叠，第 4 关之后敌人就已经追不上了。玩家变强的速度远快于难度上涨。

**V2 的解法**：同一支部队从头打到尾。

| 规则 | 说明 |
|---|---|
| 开局部队 | `帥 车 兵 兵`（一车双兵） |
| 阵亡 | 被吃掉的红子**永久离开**部队名册 |
| 每关摆位 | 按固定阵型摆到己方半场；同类子多了就依次占下一个空位 |
| 补给 | 关卡表在指定关一次性补；奖励池的补子立刻生效 |
| 上限 | 兵 ≤5，马/炮/仕/相 ≤2（受 `MAX_COUNT` 约束） |
| 全灭 | 非帅子归零 → 立刻判「部队打光了」 |
| 重打 | 护甲重打本关时，部队回滚到本关开始时的快照 |

固定阵型（`HOME`）：帅 e0 · 车 a0/i0 · 马 b0/h0 · 炮 b2/h2 · 仕 d0/f0 · 相 c0/g0 ·
兵 a3/c3/e3/g3/i3。

**这条规则带来的连锁效果**：

1. **走法升级可能作废**。兵全灭之后，`兵T2` 就是废牌，所以候选池会按部队现状过滤——
   部队里没有的兵种不出升级。丢子不只丢子力，还丢你之前买的强化。
2. **歼灭目标要慎用**。继承制下「吃光对方」等于逼你换子。所以歼灭只放在敌方没有
   攻击子的关卡（第 1、4 关）。
3. **补子变贵**。V1 的「增兵」是每关补一个，等于白送 8 个子。现在补一次就没了，
   而且有上限，所以「要不要补人」是真正的取舍。

## 8.1 关卡表（已实现的 8 关）

每关只写**敌方布置**（`enemy`，10 行 FEN，只含黑子），红方位置由部队在运行时合成，
所以红子永远在 rank 0–3、敌方永远在 rank 5–9，不可能撞位。
`tools/validate-levels.mjs` 用同一套合成逻辑校验（局面合法、非走子方不被将军、
tier 0 走法数与经典引擎一致），并打印双方子力估值。

对手一律**标准走法**，难度只靠子力和阵型，所以每关差别一眼可见。

| # | 名称 | 目标 | 敌方构成 | 子力 | 新东西 |
|---|---|---|---|---|---|
| 1 | 残兵 | 歼灭 | 将、卒×3 | 3 | 三个卒 |
| 2 | 隔山 | 擒王 | 将、士×2、马、卒×2 | 10 | 双士 + 马 |
| 3 | 对攻 | 擒王 | 将、车、炮、卒×2 | 15.5 | 车 + 炮 |
| 4 | 铁壁 | 歼灭 | 将、士×2、象×2、炮、卒×2 | 14.5 | 纯守子，歼灭安全 |
| 5 | 孤军 | 擒王 | 将、车、马、炮、卒×2 | 19.5 | 车马炮齐（打完开补给铺） |
| 6 | 混战 | 擒王 | 将、士、车×2、马、卒×3 | 27 | 双车 + 马 |
| 7 | 暗流 | 擒王 | 将、士×2、车×2、马、卒×3 | 29 | 双车双士 + 马 |
| 8 | 决战 | 擒王 | 将、士×2、车×2、马×2、炮、卒×4 | 38.5 | 双车双马 + 炮，九宫双士 |

敌方子力曲线 3 → 38.5（V2 之前的版本后半程只有 25 左右，玩家抱怨看不到几辆车，
所以第 6 关起就上双车，第 8 关连马都成对）。玩家"不损失"时约 11 → 22.5，
后半程是**以少打多**，得靠奖励和补给铺补回来。

## 9. 奖励与 build

**已实现**：每关胜利 → **三选一**，候选从下面三个池里抽，随机不放回。
同一屏里不会出现两个同类型的走法升级（那等于浪费一个选择位）。

| 池 | 内容 |
|---|---|
| 走法升级 | 某类子 +1 档，作用于你**所有**这类子；**部队里没有该类子时不出** |
| 补子 | 增兵 / 轻骑 / 炮队 / 近卫 / 守备：立刻往部队里加一个（有上限） |
| 被动 | 帅护甲 / 战利品 |

另外有 40% 概率把最后一张换成**代价型**：

| 代价 | 内容 |
|---|---|
| 血酬 | 立刻再选 2 次升级；之后每一关黑方多 1 个卒 |

**为什么强化按「类型」而不是「某一枚棋子」**：棋子会死。若强化绑在具体棋子上，
玩家会为了保住它而不敢换子，整局节奏黏住，而且一次失误就等于白扔一个奖励。
按类型则失败只会损失一个兵，build 本身留在身上。

**为什么被动只做「多一个子」这类**：一击必杀模型下，"防御力 +1" 是无意义的数字。
被动唯一有效的方向是**乘算已有投资**——你升了兵，就多给你一个兵；
你升了马，就多给你一个马。护甲则作用于另一个轴（容错），让你敢用激进 build。

**抽取是纯随机的**，只做了三条保护：排除已满档的、排除兵种已全灭的、
一屏不出两个同类型升级。如果实测下来玩家一整局凑不出 combo，再考虑加协同加权。

## 9.1 失败、护甲与悔棋

| 情况 | 结果 |
|---|---|
| 输掉一关且护甲 > 0 | 扣 1 层护甲，重打本关；**部队回滚到本关开始**，强化全部保留 |
| 输掉一关且护甲 = 0 | run 结束，回到第 1 关 |
| 主动点「重开本关」 | 同样回滚部队到本关开始（等于 SL），但本关金币和关卡表补给不会重发 |
| 点「悔棋符」 | 消耗 1 张悔棋符，退回上一步（含黑方的应招），阵亡的子回到部队 |

护甲初始 1 层，靠被动或补给铺加到最多 3 层。这是让玩家敢试 build 的关键——
否则一次失误就把 7 次奖励的选择全废了。

部队回滚是必须的：继承制下"重打"如果不还兵，一次失败会同时扣掉容错和子力，
等于双重惩罚。同理，悔棋从"随时可用的按钮"变成**要花钱买的道具**，
否则它会把整个继承制变成一句空话。

## 9.2 金币与补给铺

**金币**在每关通关时结算，只看步数：

```
金币 = 关卡基础金币 + 2 × max(0, par − 你走的步数)
```

`par` 和基础金币都写在关卡表里，越往后给的越多（12 → 28）。走得干净是唯一变量，
所以它奖励的是"打得好"而不是"打得久"。

**补给铺**每 5 关开一次（当前 8 关一局 → 第 5 关打完开一次）。库存不是固定表，
而是**按 run 状态实时算**：

| 商品 | 价格 | 备注 |
|---|---|---|
| 走法升级 | 22 / 34 / 46 | 按目标档位；该兵种已全灭则不上架 |
| 补一个兵 / 仕 / 相 | 16 / 22 / 22 | 到达上限则不上架 |
| 补一个马 / 炮 | 34 / 34 | 同上 |
| 帅护甲 | 30 | 满 3 层后不上架 |
| 悔棋符 | 14 | 可以反复买 |

买完立刻刷新货架，所以升了一档会直接看到下一档。买多少都行，退出靠「离开」。

一次性结算的金币总量（一路按 par 打完约 150）刻意只够买三到四件：
够做一次真正的取舍，不够全都要。

## 9.3 存档

侧栏有三个按钮：**保存 / 读取 / 从头开始**，存在 localStorage（`xq.rogue.save.v1`）。

存档只记**关卡开始**的状态（`roster` 取自 `run.snapshot`），读档 = 从该关开头重来。
这样不用把整盘棋和历史记谱塞进存档，而且和"重开本关回滚"是同一套语义。

存的字段：`level / roster / tiers / passives / armor / gold / items / extraBlackPawns /
granted / shopsSeen`。`granted` 和 `shopsSeen` 是关键——不存它们，读档后能反复刷
关卡表补给和补给铺。存档带版本号，版本不符会拒绝读取而不是读出一半。

## 10. 技术架构

```
js/rogue/
  xiangqi.js   棋盘表示、FEN 读写、tier 感知走法生成、make/unmake、attacked/check、perft
  ai.js        迭代加深 alpha-beta + 静态搜索 + 子力位置表（在 clone 上搜索）
  levels.js    8 关的敌方布置 + 目标 + 补给 + par/金币 + AI 参数
  run.js       部队名册、阵型填充、buildFen 合成、tiers / passives / 护甲 / 金币 / 道具、存档序列化
  rewards.js   走法等级表、被动表、奖励抽取与施加
  shop.js      补给铺库存（按 run 状态实时算）与购买
  app.js       UI：渲染、走子、AI 轮次、重复局面、奖励/商店面板、金币结算、存读档
```

- **完全独立于 `js/rules.js`**：现有引擎是标准象棋的忠实实现，改动它会同时污染经典模式。roguelike 用新引擎，只在 FEN 格式上保持兼容。
- **局面是合成出来的**：`buildFen(run, level)` = 敌方布置 + 按部队摆出的红方阵型，没有手写的完整 FEN。
- **AI 强度旋钮**：搜索深度（2–5）、时间上限、评估噪声。关卡越后越深。
- **AI 怕升级后的子**：升级只加宽走法，走法生成器已经处理，所以搜索天然把「后」的斜线当成和直线一样危险；
  另外子力估值按 tier 取值（车 T1 = 1350），否则它会把「后」当成普通车去换。
- **渲染复用**：`styles.css` 的棋盘/棋子层直接复用，`rogue.css` 只加 HUD、奖励/商店面板和 toast。
- **未做**：暗棋、战技、气。

## 11. 里程碑

| 版本 | 内容 | 验收标准 |
|---|---|---|
| **V0** | 新引擎（走法 + 吃子 + 开火）、AI、3 关残局、无技能无暗棋 | 能下完、AI 不犯低级错误、赢得不舒服也不憋屈 |
| **V1** | 兵/炮/马/车 的 T1–T2 升级、三选一奖励、护甲、气 | 完整体验一次 3 关 run |
| **V2** | 战技 6 个、被动 5 个、敌人特性 4 个、8 关 | 完整 run 打完 |
| **V3** | 暗棋翻开 + 探照/天眼、AI 难度曲线 | 信息博弈成立 |
| **V4** | Boss（Pikafish）、关卡地图、存档、解锁 | 可重复游玩 |

> **V0 是生死关**：如果一击必杀 + 走法升级的数值手感不对，后面全是白搭。V0 完成后必须先自己玩 20 局再决定要不要继续。

## 12. 风险与未定项

| 风险 | 缓解 |
|---|---|
| AI 太强或太弱 | V0 就做深度/噪声旋钮，每关单独配 |
| 走法升级导致数值失衡（比如 T3 兵太强） | 用第 2.1 节的子力值做预算，每关敌方子力 ≈ 我方 × 1.1–1.4 |
| 暗棋让玩家觉得"被偷看" | 只用一次性的"暗桩"特性 + 探照战技；不做全盘迷雾 |
| 内容量（24 个升级 + 11 个战技 + 8 关） | V1 只做 8 个升级就够跑通循环 |
| "守城"类关卡可能很无聊 | 只在第 5 关放一次，且敌方有强攻特性 |

**待定**：
1. 战技槽是 2 个固定，还是随成长增加到 3 个？
2. 精英标记要不要让玩家自己选给哪个子？
3. 是否允许"弃子换气"这种资源循环？
4. 经典模式与 roguelike 的入口怎么放（顶部 tab？还是 `?mode=rogue`？）
